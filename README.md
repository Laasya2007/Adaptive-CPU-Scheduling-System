Adaptive CPU Scheduling System

An advanced CPU scheduling system implementing hybrid and adaptive algorithms.

Features

- FCFS, SJF, Round Robin, Priority Scheduling  
- Hybrid scheduling algorithm  
- Dynamic time quantum (RR optimization)  
- Starvation prevention using aging  
- Performance metrics (Waiting Time, Turnaround Time)  
- Gantt Chart visualization  

Technologies

- C (core scheduling logic)  
- Python (extensions / ML concepts)  

How to Run

Compile:
gcc scheduler.c -o scheduler  

Run:
./scheduler
